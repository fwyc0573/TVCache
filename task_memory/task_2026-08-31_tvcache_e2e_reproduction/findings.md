- **Evidence** — The repository inventory contains `train/` and `tvcache/`, but no `video-agent-tools/` directory even though `train/README.md` points to it. This is an unresolved E2E prerequisite gap, not yet a run result.

- **Evidence** — `train/agent_loop.py`, `train/cached_agent_loop.py`, and `train/tvc_agent_loop.py` create per-rollout files under `./rollouts/{sandbox_id}.log` and emit phase markers such as `[GEN-TIME]`, `[TOOL-TIME]`, `[PARSE-ERROR]`, and (for stateless cache) `[CACHE-HIT]/[CACHE-MISS]`.

- **Evidence** — `train/README.md` instructs users to run `./run.sh`, but `find train -maxdepth 2 -type f` and `ls -la train` show no `run.sh` in this checkout.

- **Inference** — A reliable manual guide must pin an explicit server port and tell the reader which client implementation is in use; otherwise the synchronous smoke test and async training client can silently talk to different ports.
- **Evidence** — Environment preflight observed system Python `3.12.3` and `uv 0.11.14`; `tvcache/server/.venv` uses Python `3.10.20` and has Flask/requests but not httpx/pytest; no `train/.venv` exists and the system interpreter cannot import `chz`, `datasets`, `tinker`, `tinker_cookbook`, or `tvclient`.
- **Evidence** — `train/EgoSchema/processed_videos.json`, `questions.json`, and `subset_answers.json` are present, but `train/EgoSchema/videos/` is absent. The dataset metadata step therefore exists while the video execution backend/data is not ready in this checkout.
